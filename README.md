# Funniest Cat Voicemail Greeting

A one-line voicemail greeting in the voice of a cat who cannot come to the phone.

## The entry

> Can't come to the phone. Coughing up a hairball the size of a second cat. Call back when the rug's clean.

## How to run

python3 main.py

The program writes `entry.txt` (105 characters, UTF-8, no trailing newline) into the directory given by `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
